Photonic lanterns can be characterized in terms of transfer matrices, which describe the complex-valued coupling from each LP mode to each principal mode/correspondingly the strength of the fundamental single mode at each output port. Write a script that calculates the transfer matrix of a PL simulation done with save_lantern_design using lightbeam, and check that projecting a focal-plane electric field onto the LP modes and multiplying by this transfer matrix yields the same result as projecting directly onto the principal modes as done in simulation.py. Use fewer lines of code wherever possible and keep the implementation simple. Check the resulting transfer matrix against one calculated using _cbeam_, which was validated to give the same results as _espeon_ in ~/projects/plwfs_sim_sandbox.
